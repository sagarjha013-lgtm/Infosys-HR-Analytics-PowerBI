# Infosys – HR Analytics & Employee Attrition Dashboard
Power BI HR Analytics Dashboard for employee attrition, workforce and satisfaction analysis.

## Project Overview
This project showcases an interactive HR Analytics Dashboard developed using Microsoft Power BI. It analyzes employee demographics, workforce distribution, employee attrition, job satisfaction, and other HR metrics to demonstrate data-driven decision-making.

**Disclaimer:** This is an independent portfolio project created for learning and demonstration purposes. It is not an official Infosys dashboard and does not use verified internal Infosys employee data.

## Project Objectives
- Monitor total and active employees.
- Analyze employee attrition count and attrition rate.
- Understand workforce demographics by age group and gender.
- Explore attrition across departments and job roles.
- Analyze job satisfaction and salary distribution.
- Present key HR metrics in an interactive dashboard.

## Key Performance Indicators (KPIs)
- Total Employees
- Active Employees
- Attrition Count
- Attrition Rate (%)
- Average Age
- Average Experience (Years)
